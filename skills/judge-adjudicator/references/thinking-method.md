# Thinking method: seven decision checks

Use this as an implementation/calibration reference, not a request to expose hidden deliberation. The public fields are a concise decision audit.

1. **Fix the decision.** What is the user deciding now? What counts as success: learning, a demo, a community pilot or revenue? Separate building an app from testing a manual service. If the goal is missing, fail input validation rather than guessing.
2. **Locate the load-bearing assumption.** Ask which claim, if false, most changes that next step. Do not rank by how dramatically an advocate phrases it.
3. **Audit support and rebuttal.** For every claim, compare exact source meaning, population, timing and scope. A club sharing an invitation supports access, not successful matches. A quote can be genuine while its inference is false.
4. **Assess dimensions separately.** Fill the five anchored rubric entries before choosing the action; null is a legitimate unknown. Do not bend each dimension toward an early overall impression. These are assessments of the idea's next step, not ratings of the two speakers.
5. **Test the value of another question.** Name one claim, existing evidence, the ambiguity and two answers that lead to different action labels. If the answer needs a future trial, stop. If the answer would not change action, stop. This is qualitative decision relevance, not a numeric expected-value calculation.
6. **Choose the limited action.** Prefer a warranted bounded pilot to unnecessary abstention, but prefer a test to a speculative build. Recognize supported fatal constraints without calling all uncertainty failure. Neither side must win.
7. **Make the verdict falsifiable.** Preserve dissent, name one next experiment with proposed criteria, and state what evidence would alter the action. Thresholds are proposed planning choices, not scientific constants.

Example: both sides dispute whether '12 attendees' means 12 unique people or six repeat visits. A supplied roster and attendance table can settle it: one clarification may help. If they dispute whether anyone will return next month and no follow-up exists, more debate cannot settle it: stop and test repeat use.

Do not request a step-by-step chain-of-thought. Only retain claim findings, rubric reasons and short action justifications. No experiment can certify business success from a tiny sample.
